# Ежедневник (Daily Planner)

Проект «Ежедневник» с графическим интерфейсом на Python. Позволяет добавлять, просматривать, удалять и искать заметки по датам. Данные сохраняются в JSON-файл.

## Возможности
- Добавление нескольких заметок на одну дату.
- Удаление одной заметки или очистка целого дня.
- Поиск по тексту всех заметок (без учёта регистра).
- Быстрый переход к дате из результатов поиска (двойной клик).
- Хранение данных в структурированном JSON.

## Требования
- Python 3.6 или новее.
- Стандартная библиотека `tkinter` (входит в установку Python для Windows/macOS; в Linux может потребоваться `python3-tk`).

## Запуск
1. Скачайте файлы проекта.
2. Откройте терминал в папке с проектом.
3. Выполните команду:
   ```bash
   python main.py
